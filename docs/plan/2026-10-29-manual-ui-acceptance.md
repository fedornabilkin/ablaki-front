# Ручная приёмка интерфейса

Цель: сохранить незавершённые ручные проверки отдельно от уже выполненных реализаций. Актуализация 2026-10-29; отсутствие браузера в старой сессии не является новым дефектом.

## Группа A: Проверки прежних пакетов

- [ ] A1. На узком экране проверить списки сообщества, поля фильтров, модалку онлайна, настоящие ссылки и Back/Forward. Перенесено без выполнения из `2026-09-06-community-lists.md:C3`.
- [ ] A2. На телефоне проверить карту мастерской, сундук, перенос вещи и положение курсора/выделения. Перенесено без выполнения из `2026-09-26-forum-72.md:C3`.
- [ ] A3. Под реальным p-admin на test проверить редакторы каталога, preview, импорт/экспорт и отображение ошибок без изменения имущества игроков. Перенесено без выполнения из backend `2026-09-20-classic-crafting.md:D5`.

## Группа B: Текущий MVP

- [ ] B1. Закрыть [UI:E2](2026-10-15-world-closed-test-ui.md) и [CONUI:E2](2026-10-16-world-economy-content-ui.md): маршрут двух обычных участников на 360/390/768/1280 px, клавиатура, фокус, карта, крафт, размещение, добыча, мини-склад, лимиты, еда, ночлег и казна.
- [ ] B2. Сохранить результаты и замечания через [чеклист](../operations/world-mvp-checklist.md), скачать JSON и передать в [ACC:C4](../../../back/docs/plan/2026-10-15-world-closed-test-acceptance.md). Указать локальные и тестовые версии отдельно; локальный чеклист не считать опубликованным на test.

Критерий готовности: каждая проверка имеет реальный результат, контур/версию и воспроизводимые замечания. Автоматические тесты и успешная сборка подтверждают свою область, но не заменяют визуальную приёмку.
