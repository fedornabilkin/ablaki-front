## Цель и контекст

После подключения новой модели мира маршруты `/world` переключились на упрощённый список. Вернуть существующие карты, сведения об объектах, выделение рамкой и нескольких объектов, перетаскивание вещей, исследование и покупку ячеек. Сохранить новое строительство и округлять подписи кредитов до десятых.

## Критерии готовности

Маршруты показывают прежний интерактивный экран; новое строительство доступно во вкладке развития. В денежных подписях нет четырёх знаков после запятой. Проверки проходят, исправление доступно в test и локально.

## Проверка

`npm run test:unit`: 256 тестов в 46 файлах. `npm run build`: успешно. Проверены реальные Vue-шаблоны бюджетов, начала строительства, карты и хранилищ: выделение рамкой, перетаскивание, защита от изменения цены, округление только отображаемых сумм. Тестовый API от Test01 возвращает карту с иерархией, исследованием и ценами, хранилища, варианты размещения, экономику, огород, шалаш и ночлег с HTTP 200. Ответ карты принят строгим frontend-парсером. `http://localhost:5173/world` отвечает HTTP 200.

Визуальная проверка ограничена: browser/computer-use в этой сессии сообщил `No browser is available`. Проверки Vue-шаблонов выполнены через имеющийся тестовый renderer, без утверждения о проверке скриншотов.
