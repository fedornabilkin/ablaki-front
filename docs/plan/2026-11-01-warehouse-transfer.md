# Перенос вещей в хозсклад

Цель: освободить рюкзак через ячейки хозсклада. Контекст: запасы уже существуют на backend, но интерфейс выбирал размещение и показывал только выдачу продукции.

## Группа A: Интерфейс
- [x] A1. Использовать общий интерфейс ячеек склада и рюкзака на странице собственного склада; открывать запасы вместо размещения.
- [x] A2. Сохранить покупку чужих товаров и отдельный режим продажи. Добавить переход из мини-склада и компактную сетку на телефоне.
- [x] A3. Проверить переполненный рюкзак, перенос в обе стороны, запреты и повтор команды на временной БД; добавить проверки интерфейса.

## Группа B: Выпуск
- [x] B1. Полный набор тестов frontend и сборка: 486 тестов / 55 файлов; Vite build успешен.
- [ ] B2. Опубликовать frontend и сверить SHA. Описать ограничения ручной проверки браузера.

Готовность: собственный склад открывается вместе с рюкзаком, предмет сверх лимита можно убрать, повторы/отказы сохраняют количество. Гостевая покупка сохраняется. На мобильном сетка ограничена по высоте, используются прежние перенос по касанию и общие поповеры.

Ручной осмотр не выполнен: подключение к встроенной вкладке недоступно; computer-use остановил проверку Яндекс Браузера из-за отсутствия поддержки проверки адресов. Production-инвентарь пользователя для тестов не менялся.
