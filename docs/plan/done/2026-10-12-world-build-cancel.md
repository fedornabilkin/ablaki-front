# Плитки размещения и отмена строительства

Цель: оформить доступные плитки как рецепты мастерской и корректно отменять новую стройку.

Контекст: прямые пожелания владельца от 2026-10-12; изменения ограничены миром.

## Группа A: Оформление

- [x] A1. Доступные плитки строительства и размещения имеют сплошной оранжевый контур и мягкий фон.
- [x] A2. Предмет на карте получает фон и рамку размещённого объекта, белые иконку и подпись.

## Группа B: Отмена

- [x] B1. Перед отменой новой стройки показать предупреждение о потере 30% ресурсов даже до начала работ; возврат округляется вниз.
- [x] B2. Сервер атомарно возвращает 70% материалов, архивирует объект и повышает revision родителя; повтор команды не дублирует возврат.
- [x] B3. После отмены открыть родительскую карту и обновить дерево через существующую реактивную загрузку.

## Группа C: Проверки

- [x] C1. Проверить подтверждение и смену сессии компонентными тестами; пройти 301 unit-тест и production build.
- [x] C2. Проверить отмену до и после начала работ в отдельной PostgreSQL-БД с откатом; проверить сохранение ремонта.
- [x] C3. В браузере проверить реальные цвета, белые иконку и подпись предмета, модалку на 390 px и реактивный переход к карте без отменённого объекта. Команды браузера изолированы адаптером; реальные записи не выполнялись.

Критерии готовности: подтверждение обязательно, материалы возвращаются по серверному правилу, отменённый объект не выдаётся карте; плитки и предметы соответствуют запросу.
