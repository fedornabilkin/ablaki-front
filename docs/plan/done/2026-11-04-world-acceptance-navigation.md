# Навигация и обратная связь при приёмке мира

Цель: сделать доступность изготовления и размещения понятной, сохранить выбор рецепта в ссылке и автоматически учитывать игровые этапы.

Контекст: замечания владельца от 2026-11-04; существующие компоненты мира и серверные ограничения сохраняются.

## Группа A: Изготовление
- [x] A1. Цветовые состояния карточек, состав и количество материалов, ссылки на изготовление компонентов.
- [x] A2. Выбор рецепта в URL, открытие ссылки и история переходов.

## Группа B: Карта и склад
- [x] B1. Два прокручиваемых каталога по сторонам карты; полный перечень и состояния доступности.
- [x] B2. Поповер покупки у выбранной ячейки склада, проверка узкого экрана.
- [x] B3. Отличительная отметка своей стоянки на карте города.

## Группа C: Прогресс и проверка
- [x] C1. Автоматические игровые этапы по полному серверному прогрессу, понятные незавершённые условия.
- [x] C2. Поведенческие тесты, сборка и визуальная проверка мобильного и широкого экранов.

Критерии готовности: все пункты проверены; недоступные действия объясняются; ссылки воспроизводят выбор; нет горизонтального переполнения.
