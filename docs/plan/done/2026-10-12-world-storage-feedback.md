# Уточнение оформления и доступности слотов

Цель: согласовать цвета мира с хедером, отличать покупку от переноса, показывать занятые объектами слоты и убрать ошибку расширения оборудования в шалаше.

Контекст: пожелания владельца от 2026-10-12 после проверки страницы хранилища.

## Группа A: Оформление

- [x] A1. Кнопки мира используют CSS-цвет хедера `--primary`; фокус сохраняет основной оранжевый, hover/press используют более тёмный `--primary-press`.
- [x] A2. Выбранное хранилище обвести тёмным оранжевым `#a74700`; убрать видимую подпись «Правое хранилище».
- [x] A3. Ячейки к покупке показывать со сплошной рамкой; пунктир оставить только доступным целям переноса.

## Группа B: Доступность

- [x] B1. По координатам/footprint дочерних объектов отметить занятые слоты названием и иконкой объекта, подписью «Недоступно для размещения» и исключить их из целей клика/drag-and-drop. Доступ к уже лежащим предметам сохранён.
- [x] B2. Разделить расширения ночлега и оборудования: API объявляет `equipment_expansion` для ROOM, UI подключает блок только по этому признаку; BUILDING/PLACE больше не запрашивают несовместимый endpoint.

## Группа C: Проверка

- [x] C1. Проверить footprint, блокировку переноса и сохранность общих сценариев: 299/299 unit-тестов, 46 файлов; production-сборка успешна с прежним предупреждением о крупных chunks.
- [x] C2. Проверить PHP lint, совместимость синтаксиса PHP 7.3 и расширения всех девяти типов нод; дополнительных SQL для объявления расширения нет.
- [x] C3. Проверить реальный локальный API и браузер: цвет фона кнопки совпадает с цветом бренда, включая focus; hover и обводка темнее; четыре объекта запрещают размещение, четыре ячейки покупки имеют сплошные границы и одна свободная цель — пунктир. В шалаше нет блока/запроса оборудования и ошибки. Desktop и 390 px без ошибок JS/Vue; запись в БД не выполнялась.

Готовность: интерфейс проверен по всем пожеланиям. Изменения находятся в локальном проекте; публикация не выполнялась. Артефакты: `temp/world-storage-feedback/`, служебный файл браузерной сессии удалён.
