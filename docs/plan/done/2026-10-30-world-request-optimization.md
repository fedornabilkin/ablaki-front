# Запросы мира и gzip

Цель: убрать постоянные запросы без активного действия и сжимать текстовые файлы фронтенда.

## Группа A: Запросы

- [x] A1. Удалить безусловное обновление карты каждые 30 секунд; сохранять обновления по действиям и навигации.
- [x] A2. Опрос добычи выполнять только для подтверждённой работающей сессии; остановить на паузе, после ошибки, при скрытой странице/панели.
- [x] A3. Устранить повторные запросы просроченного урожая, лишнюю загрузку каталога культур и дубли обновления заданий.
- [x] A4. Ограничить опрос строительства активным трудом/действительно работающими помощниками и видимой панелью.

## Группа B: Сжатие и проверка

- [x] B1. Включить gzip HTML/JS/CSS/JSON/SVG в конфигурациях nginx frontend с корректным Vary и сохранением кеширования.
- [x] B2. Проверить таймеры/паузы/возобновление/смену сессии существующими тестами, выполнить unit/build и deployment-проверки.
- [x] B3. Проверить gzip реальным nginx и HTTP, записать замеры и ограничения применения на стенде.

Результат: 419 unit-тестов в 55 файлах, 49 deployment-проверок и сборка прошли. Gzip проверен реальными HTTP-ответами nginx, байты после распаковки совпадают. Подробности: [отчёт](../../operations/world-requests-gzip-2026-10-30.md). Код подключён локально; новая test/production-выкладка в эту задачу не входит, существующий gzip на test подтверждён read-only запросами.
