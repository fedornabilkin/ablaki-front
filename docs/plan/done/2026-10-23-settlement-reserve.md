# Заселение, дочерняя стройка и обратная связь

Цель: до вступления показывать обеспеченные места, вести дочернюю стройку с карты родителя и завершить порученные изменения интерфейса. Сервер хранит деньги и права; локальный игровой процесс сохраняется.

## Группа A: Заселение и строительство

- [x] A1. Показать ставку города и число мест города/региона из защищённого стартового резерва, отдельно объяснить очередь без средств.
- [x] A2. Нормализовать пустой бюджет строителей в ноль; проверить свободный бюджет, явную личную доплату и защиту принятой оплаты помощников.
- [x] A3. Встроить работу над дочерним объектом в карту родителя с прогрессом и heartbeat, без принудительного перехода внутрь.

## Группа B: Интерфейс

- [x] B1. Обновить иконку сбора и поднять сообщение о полученном сырье с отступом.
- [x] B2. Раскрыть правила казны и заменять подтверждённый расчёт перевода сообщением о результате.
- [x] B3. Показать исследуемые ячейки и счётчик оставшихся шагов заданий.
- [x] B4. Закрепить все модалки сверху без скачков при смене содержимого.

## Группа C: Проверки

- [x] C1. Пройти клиентские тесты и сборку, проверить браузер на двух пользователях и админку, обновить документацию и отправить рабочую ветку.

Критерий готовности: подтверждены варианты оплаты и доступности; реальные игровые средства при проверках не начисляются, локальный прогресс не сбрасывается.

## Подтверждение

Клиент: 374 теста (55 файлов) и production-сборка проходят. В Chrome на LocalMvp01 и LocalMvp02 проверены город/регион, запрет чужого управления резервом, бейдж, мобильная ширина и неизменный верх модалок при смене вкладок/выдаче сырья. Админская форма проверена с CSRF и серверной валидацией. UI сбора проверялся с изолированным ID и ответом, без изменения игрового инвентаря. Варианты нулевого/положительного бюджета и работа с картой родителя проверены поведенческими тестами. Логи и снимки — `temp/settlement-reserve` вне Git.
