# Общие списки и функции сообщества

## Актуализация 2026-10-29

API, миграции и совместный выпуск выполнены последующими пакетами [списков API](../../../../back/docs/plan/done/2026-09-05-frontend-list-api.md), [метаданных сообщества](../../../../back/docs/plan/done/2026-09-06-community-list-metadata.md) и [production-релиза](2026-09-14-production-release.md). Исторические ограничения первого этапа ниже больше не блокируют этот пакет.


Цель: выполнить пользовательский запрос на серверные списки, URL-состояние, хедер, статистику и игровые/форумные возможности. Разработка непосредственно в master frontend и backend, работа четырьмя потоками с разделённым владением файлами.

Критерий готовности: общий UI подключён ко всем доступным спискам, API фильтрует до подсчёта/пагинации, суммы и онлайн не выдумываются; production-операции не выполняются в тестах. Миграции и PostgreSQL/MySQL concurrency требуют отдельной проверки целевого окружения.

Результаты локальной проверки: [отчёт](../../reports/lists-and-community-verification.md). Публикация frontend зависит от обновления API: push master запускает production deploy автоматически.
