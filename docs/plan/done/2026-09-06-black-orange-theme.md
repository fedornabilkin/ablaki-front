# Тёмно-оранжевая тема

## Цель и контекст
Привести действующий frontend к `mockup/black-orange.html`, сохранив Naive UI,
реальные данные, маршруты и существующие сценарии. Общая палитра уже находится
в `project/src/theme/tokens.ts`; сохраняем этот единый источник для CSS и Naive UI.
Master синхронизирован с origin перед изменениями; рабочая копия была чистой.

## Группа A: Оформление
- [x] A1. Согласовать палитру, размеры и состояния Naive UI с мокапом.
- [x] A2. Обновить шапку, мобильное меню и заголовки страниц.
- [x] A3. Применить готовые кнопки и иконки к карточкам и навигации игр.

## Группа B: Адаптивность и проверка
- [x] B1. Исправить узкие колонки фильтров, пагинацию и размеры модальных окон.
- [x] B2. Проверить мобильный, планшетный и настольный интерфейс в браузере.
- [x] B3. Выполнить test:unit и build, записать результаты и ограничения.

## Критерии готовности
Тема использует общий источник цветов, интерактивные элементы удобны для касания,
страницы не расширяют мобильный экран; меню и модальные окна доступны с клавиатуры.
Не добавлены зависимости, демонстрационные данные и изменения API.

## Результаты проверки
- `npm run test:unit`: 72 теста в 11 файлах пройдены.
- `npm run build`: успешно; сохраняется предупреждение о размере общего UI-чанка (около 557 kB).
- `git diff --check`: успешно.
- Главная: 320, 360, 414, 768, 1024, 1440 px — ширина документа не превышает viewport.
- Вход, регистрация, статистика: 360, 768, 1024 px; форум: 360, 768, 1024 px;
  каталог игр визуально проверен на 360 px. Горизонтального переполнения не обнаружено.
- Мобильная панель: пункты входа/регистрации, переход в каталог, закрытие по Escape,
  возврат фокуса кнопке. Онлайн-модалка: размещение на мобильном экране и закрытие по Escape.
- Прокрутка форума: шапка закреплена у верхнего края, компактное состояние включается,
  кнопка меню остаётся высотой 44 px.
- API форума вернул реальные темы. Запросы участников и пользователей онлайн показали
  серверную ошибку; проверено отображение ошибки и кнопки повтора, исправление API вне задачи.
- Авторизованные страницы, реальные игровые операции и создание заявок в браузере
  не проверялись: тестовая сессия не авторизована. Изменения их размеров проверены сборкой;
  для поля сапёра предусмотрена локальная прокрутка с минимальной шириной клетки 2.75rem.
- Проверки запускались вне файловой песочницы: внутри неё сборщик не мог прочитать
  конфигурацию из-за ограничений доступа к родительскому каталогу.
- На этапе визуальной проверки публикация и push не выполнялись. Владелец затем
  разрешил закоммитить оставшиеся изменения темы и отправить их в origin/master;
  push запускает штатные CI и деплой.
