# Единая навигация крафта в мире

Цель: собрать инвентарь, рецепты, карту рецептов и историю в `/world/workspace` и убрать неоднозначные входы крафта.

Контекст: четыре раздела были локальными вкладками `/craft`; `/craft?node=…` переключал отдельную мастерскую. `/world/workspace/:id` содержит изготовление с оборудованием и хранилищами объекта и остаётся необходимым контекстным экраном. Старые `Craft.vue` и Vuex-компоненты не имеют публичного маршрута; магазин материалов ещё использует их доменное состояние, поэтому оно не удаляется.

## Группа A: Маршруты

- [x] A1. Создать отдельные URL inventory, recipes, map, history под `/world/workspace` с общей навигацией.
- [x] A2. Сохранить числовой маршрут изготовления; назвать экран «Изготовление: объект».
- [x] A3. Перенаправить `/craft`, сохраняя предмет, рецепт, объект и hash; удалить неиспользуемый переключатель CraftEntry.

## Группа B: Связи

- [x] B1. Связать рецепты и карту с изготовлением; убрать дублирующую отправку классической команды изготовления из каталога.
- [x] B2. Сохранить контекст объекта при переходах из его изготовления в четыре раздела.
- [x] B3. Обновить ссылки мира, заказов, магазина материалов и крошки; показать четыре раздела во вкладке «Вещи и крафт».
- [x] B4. На инвентаре и истории скрыть фильтр ремёсел; убрать сбор сырья из общего каталога и сохранить URL страниц истории.

## Группа C: Проверки

- [x] C1. Пройти 307 unit-тестов и сборку; прежнее предупреждение о размере chunks сохранено.
- [x] C2. Проверить четыре прямых адреса, старые ссылки, изготовление, навигацию назад, ссылки ресурсов и мобильный экран в браузере с реальным API. Серверные команды не выполнялись; расчёт craft-preview только читает условия.
- [x] C3. Сохранить выбранный рецепт в видимой области карты после перехода с desktop на mobile.

Артефакты: `temp/world-workspace-navigation/` в общей рабочей папке.

Критерии готовности: четыре понятных адресуемых раздела, изготовление только с контекстом объекта, работающие старые URL и отсутствие ссылок интерфейса на `/craft`.
