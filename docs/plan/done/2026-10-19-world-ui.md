Цель: выполнить пакет замечаний владельца от 2026-10-19. Контекст: ветка `feature/09-worlds`, существующие Vue/Naive UI и серверные команды; без новых библиотек.

- [x] A1. Открывать онлайн обычной кнопкой без изменения URL.
- [x] A2. Сохранять экземпляры онлайна и ежедневного бонуса при смене компактного хедера; обновлять количество без исчезновения кнопки.

- [x] A4. Оформить шаги карточками с состоянием, прогрессом, наградой и кнопками перехода.
- [x] A5. Сделать вкладки «Лагерь», «Ресурсы», «Лимиты», «Здоровье».

- [x] B4. Оставить на вкладке казны одну форму пополнения.
- [x] B5. Показывать сведения выбранной ячейки сразу под картой при ширине до 760 px.
- [x] B6. Убрать игровой блок переноса объекта со вкладки управления.
- [x] B7. Сделать «Очистить грядку» красной кнопкой с крестиком, а отмену строительства — красной кнопкой «Отменить».
- [x] B8. Убрать подсказки строительства и добычи под значок справа в заголовке; на плитках показывать длительность с часами и пояснением при наведении.
- [x] B9. Сократить сменяющие друг друга запросы вариантов размещения задержкой 120 мс; сохранять плитки во время обновления.

## Группа C: Прогресс и проверка

- [x] C1. Непрерывно заполнять шкалу работы между серверными снимками, ограничивая проекцию окном связи в 60 секунд.
- [x] C2. Проверять работу в фоне каждые 10 секунд и при достижении конца; сохранять место шкалы и кнопки во время запросов.
- [x] C3. Исключить перезапись результата команды запоздалым чтением состояния шахты.
- [x] C4. Проверить сохранение хедера при прокрутке, четыре вкладки, создание огорода с доплатой/без неё, нулевые цены и прогресс реальным клиентским шаблоном компонентов.
- [x] C5. Выполнить `npm run test:unit` (340 тестов, 53 файла) и `npm run build`.

Критерии готовности: все пункты реализованы, проверки проходят, локальные `/world`, каталог, размещение и задания отвечают HTTP 200. Адрес: `http://127.0.0.1:5173/world`. Данные API проверены через Vite proxy.

Ограничение проверки: браузер CUA недоступен (`Browser is not available: iab`); визуальная проверка на реальном мобильном экране не выполнена. Клиентские тесты проверяют шаблоны и события, сборка — компиляцию. Сборка сохраняет предупреждение о крупном UI chunk.
