# Контекст карты и управление объектами

Цель: показать подходящие постройки и предметы по типу ноды, убрать стройку из пустой ячейки, сократить назначение ночлега и уплотнить казну. Сервер проверяет все ограничения; локальный прогресс сохраняется.

## Группа A: Карта

- [x] A1. Показывать строительство только для выбранной ячейки, сохранить одну рабочую сессию и фоновую синхронизацию.
- [x] A2. Заменить «Приостановить» на «Остановить» и добавить двойной клик для перехода к объекту.
- [x] A3. Разместить под картой вкладки «Объекты» и «Предметы», загружать предметы при первом открытии.
- [x] A4. Поддержать повышенную цену дальнего кольца и серверную фильтрацию каталогов.

## Группа B: Ночлег и финансы

- [x] B1. Назначать ночлег по выбранной кровати одним нажатием с фоновым preview и атомарной заменой прежнего назначения.
- [x] B2. Убрать пояснения под иконки и разместить все блоки казны в адаптивной сетке.

## Группа C: Проверки

- [x] C1. Пройти клиентские тесты, сборку и браузер; сохранить рабочую ветку.

Критерий готовности: сервер и клиент показывают одинаковые цены/ограничения, назначение не требует отдельного подтверждения, пустая ячейка не показывает управление стройкой.

## Результат и проверки

Остаток исходного локального участника 47,15 сходится с журналом: 250 − 20 − 50 − 10 − 120 − 2,85. Кузница снижена со 150 до 40. Самостоятельные шалаш, огород, грядка, шахта, кузница, восемь соседних ячеек со скидкой и два полива стоят 247,8. Кредиты не добавлялись. Для недельного маршрута добыча угля даёт 3, песка 4, редкой травы 2; дневной предел остаётся 20. Мастерская и средний склад перенесены в сценарии на стоянку; дополнительные эликсиры изготавливаются в рамках этого предела. Принятые партии, стройки и платежи сохраняют условия.

Схема 43 и текущий профиль установлены локально; публикация проверяет неизменность кошельков, счетов, стартового резерва, строительства и инвентаря. Пройдены PHP 7.3 lint, сценарии профиля без БД, 378 клиентских тестов в 55 файлах и production-сборка. На PostgreSQL/MySQL пройдены `world-feedback-food`, недельный `world-economy-gameplay` и `world-economy-race`. Финальная гонка шести размещений создаёт одну незавершённую стройку. Проверены родительские связи, фильтрация предметов, сохранность старого ночлега/истории и повтор операции. После изменения контекста обновлены только соответствующие фикстуры, которые ранее создавали объекты в произвольных родителях.

Chrome: реальные локальные каталоги/баланс, вкладки под картой, двойной клик, казна в три колонки на большом экране и одна на мобильном, открытие полного отчёта в модалке. На изолированных ID проверены скрытая стройка с работающим heartbeat и одно нажатие для ночлега; реальный игровой процесс при этих UI-проверках не менялся. Логи и снимки — `temp/node-placement-context` вне Git. Контракт и Insomnia обновлены. Для другого контура нужны установка схемы и явная публикация актуального профиля.
