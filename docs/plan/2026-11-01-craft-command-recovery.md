Причина: общий сохранённый запрос после HTTP 500 запрещал выбор рецепта; закрытая подсказка оставляла только «Изготовление недоступно». После окончательного отказа при повторе расчёт тоже не перезапускался.

## Группа A: Поведение
- [x] A1. Разрешить просмотр рецептов при сохранённом запросе, сохранив блокировку нового изготовления.
- [x] A2. Показать восстановление в основной кнопке и не скрывать причину блокировки.
- [x] A3. Перезапустить расчёт после окончательного отказа; не называть восстановленное действие карты изготовлением.
- [x] A4. Проверить компонентные сценарии: 119 проверок прошли.

## Группа B: Выпуск
- [x] B1. Пройти полный набор frontend-проверок и сборку: 55 файлов, 484 проверки; Vite build успешен.
