## Объединённая приёмка

Реализация интерфейса закрытого теста и экономического контента опубликована. Открытые E2 обоих пакетов объединены в B1 ручной приёмки, E3 — в B2. Чеклист доступен игрокам, а итоги двух участников ещё предстоит собрать.
