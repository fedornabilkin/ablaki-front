## Ближайшая работа

| План | Следующий результат |
| --- | --- |
| [Ручная приёмка](2026-10-29-manual-ui-acceptance.md) | Списки/онлайн, карта/сундук, p-admin-каталог и матрица текущего мира. |

Для отметок используется локальный [чеклист MVP](../operations/world-mvp-checklist.md). Его 21 пункт сохраняется в браузере отдельно по пользователю/экземпляру мира. Текущий этап — [два участника в существующем локальном мире](../../../back/docs/plan/2026-10-21-mvp-launch-readiness.md); автоматические тесты не означают, что владелец уже прошёл маршрут.
