# Выкладка только изменившегося приложения

Цель: не пересобирать и не публиковать приложение при изменении только документации или тестов; сохранить полный набор тестов перед production.

## Группа A: Выбор релиза
- [ ] A1. Сравнивать с опубликованным deploy-version.txt; при ошибке чтения или отсутствующем коммите сохранять полный прогон.
- [ ] A2. Пропускать сборку/публикацию документации; тестовые изменения проверять без выкладки.
- [ ] A3. Проверить пограничные сценарии и первый выпуск; обновить соглашения.

Готовность: предыдущий неудачный релиз не скрывает изменения, перенос файла в docs не скрывает его удаление, полный production test:full сохранён.
