Общие ТЗ хранятся в [backend/docs/tz](../../back/docs/tz/README.md), [контракт мира](../../back/docs/architecture/simple-world-api.md) — в архитектуре backend, [инструкция Insomnia](../../back/docs/operations/insomnia.md) — в эксплуатационной документации.

Текущая [модель и интерфейс мира](../../back/docs/architecture/simple-world.md): страница `/world` открывает собственный дом; выращивание находится на странице грядки. Строительство управляется справа на карте, параметры имени и бюджета — в отдельной модалке. Хранение и продажа продукции доступны на странице мини-склада. Навигация между объектами и обновление данных после команд происходят реактивно.

Стройка отображает прочность x/N с плавным прогрессом и индикатором синхронизации справа. Параметры открываются сразу при размещении; оплата сначала использует бюджет, личная доплата включается галочкой. Ячейки одного кольца имеют одинаковую цену, пакетная скидка показана отдельно. Склад на стоянке использует общий интерфейс продукции; готовая буровая внутри шахты позволяет игрокам добывать руду.

Новые файлы, полученные при проверках и тестировании, сохраняются в общей папке `../temp/<задача>/` относительно `frontend`: логи, скриншоты, выгрузки, ответы API и вспомогательные скрипты. Их не следует добавлять в Git. При переносе документа обновляются ссылки в обоих репозиториях.
