# Telegram: подтверждение входа в чате

Общий компонент `project/src/components/auth/TelegramAuth.vue` используется на страницах входа, регистрации и профиля. На сайте показываются пояснение, код сравнения, переход в Telegram, ожидание и ошибки. Автоматический вход после подтверждения выполняет Vuex `auth/loginTelegram`; профиль и хедер обновляются тем же механизмом, что и при входе паролем.

`useTelegramApproval` отвечает за последовательный опрос, TTL, отмену, сетевые повторы и восстановление текущей вкладки после возврата из Telegram. После размонтирования старые ответы игнорируются, таймеры прекращаются. Для привязки существующего аккаунта пользователь дополнительно подтверждает Telegram на сайте; новый аккаунт создаётся только с явным разрешением.

Никаких токенов бота или новых `VITE_*` переменных не нужно. Доступность поступает из `GET /auth/telegram/config`; выключенная интеграция отображается недоступной. Переключатель управляется администратором на `/auth-settings/index` и хранится в БД; env-переключатель не используется. Имя бота API получает автоматически при его запуске. Полный [API-контракт, env и регистрация бота](../../../back/docs/architecture/telegram-auth.md). [План подключения](../../../back/docs/plan/2026-11-04-telegram-auth.md) пока активен: сам бот ещё не реализован.

Проверки: `tests/telegram-auth.test.ts`, дополнения `tests/auth.test.ts`, общий unit-набор и production-сборка. Встроенный браузер проверен на обычной ширине и 390×844: на изолированном локальном API имитация bot callback автоматически открыла `/users/profile` и обновила аккаунт в интерфейсе. Это проверка website/API-контракта, а не взаимодействие с настоящим Telegram.
