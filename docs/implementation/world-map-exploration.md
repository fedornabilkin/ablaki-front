# Карта мира и исследование

Обновление feature/09-worlds от 3 октября 2026.

- Удалены дублирующие крошки внутри страницы; глобальные крошки мира остаются. Переход к родителю находится в блоке названия.
- SVG-карта целиком помещается в окно без прокрутки. Закрытая сетка рисуется одним pattern, без миллиона DOM-элементов для больших административных карт. Отрицательные координаты и абсолютные полигоны соблюдают декартову систему.
- Исследование выполняется одним нажатием при нужном уровне; альтернативная кнопка расходует один эликсир. Город и старшие уровни показывают причину недоступности. В инспекторе можно бесплатно выбрать профессию исследователя или повысить её уровень.
- Shift выбирает область исследованных ячеек, Ctrl/⌘ переключает отдельные ячейки. На сенсорном экране есть режим множественного выбора. Максимум 100 ячеек. Цена ячейки находится справа сверху, общая цена и скидка видны сразу. Выделение сохраняется при обновлении после команды.
- Preview и execute идут автоматически после одного нажатия. Клиент сравнивает цену preview с показанной; изменившаяся цена не подтверждается автоматически. Повторы используют тот же request_key.
- Кнопка входа в крафт на страницах мира доступна только на стоянке. В списке рецептов и мастерской доступные рецепты подсвечиваются; учитываются ресурсы, инструменты и станции.
- Общий formatCredits показывает целые суммы и максимум десятые, не преобразуя большие десятичные строки через Number. Применён в мире, крафте, кредитных суммах игр, профиля, биржи, переводов, форума и призового фонда. В API суммы остаются исходной точности.

Протоколы описаны в backend docs/api/world.openapi.json и world-workspace.openapi.json, примеры обновлены в Insomnia.json. Детали миграции и баланса — backend docs/implementation/world/world-map-exploration.md.
