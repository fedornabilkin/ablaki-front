# Запросы мира и gzip — 2026-10-30

По поручению владельца убраны запросы, которые выполнялись без активного действия. Бизнес-правила, игровые данные, серверная проверка денег/ресурсов и ключи повтора команд сохранены.

## Изменение количества запросов

| Сценарий | До | После |
| --- | --- | --- |
| Открытая карта без действий | Перезагрузка ветви каждые 30 секунд | Обновление по навигации, успешному действию или кнопке «Обновить» |
| Добыча ещё не началась или остановлена | GET mining каждые 10 секунд | Один начальный GET видимой панели; фоновых GET/POST нет |
| Добыча работает | Heartbeat каждые 10 секунд плюс возможные проверки завершения каждую секунду | Только подтверждённая работа, видимая панель и страница; проверки завершения и интервалы объединены с шагом не чаще 10 секунд после первой проверки |
| Ожидание подтверждения или ошибка heartbeat | Возможны новые периодические команды после отказа | Автоматический опрос прекращается; повтор выполняется тем же сохранённым запросом по действию пользователя |
| Скрытая вкладка мира или документ браузера | Часть панелей продолжала опрос | Добыча/стройка/сроки урожая не отправляют фоновые запросы |
| Стройка без работающих строителей | GET списка каждые 10 секунд | Периодических GET нет; опрос остаётся для действительно работающих помощников |
| Изменение revision стройки | Замена node могла одновременно запускать load и refresh | Один refresh; изменения идентичности проверяются отдельными значениями |
| Остановка стройки | Два события changed и повторное обновление родителя | Одно событие changed |
| Получение награды/еды | Прямой load заданий и load по revision родителя | Одна объединённая загрузка |
| Просроченный урожай | При задержке worker/ошибке GET мог повторяться каждые 5 секунд | Одна проверка конкретного срока/стопки, дальнейшее обновление по действию пользователя |
| Срок полива/созревания | Состояние грядки, каталог культур и бюджет загружались заново | Один GET состояния на переход; каталог переиспользуется в текущей странице/сессии, бюджет не читается из-за хода времени |

Для открытой карты шахты в простое убраны 8 периодических мировых запросов в минуту: 2 обновления карты и 6 GET mining. Это не число всех запросов приложения: авторизация, присутствие/счётчик онлайна и явные пользовательские действия имеют отдельное назначение.

Смена вкладки сохраняет формы и компоненты. Props `active` имеют явное значение true по умолчанию; скрытые панели откладывают загрузку/опрос. Поздние ответы предыдущей ноды/сессии игнорируются. При возвращении к подтверждённой работе heartbeat сверяет реальное состояние; он не начинает новую партию.

Кулдаун источника разблокируется по локальным монотонным часам, синхронизированным с сервером, без GET. При наступлении срока исчерпанной квоты основная кнопка предлагает «Обновить лимит»: выполняется один явный GET, без автоматического старта добычи и без придуманного клиентом остатка. Данные других игроков можно получить кнопкой обновления карты.

## Gzip

В трёх nginx-примерах frontend закреплены `gzip on`, `gzip_vary on`, уровень 5, минимум 1024 байта и MIME-типы JS/CSS/JSON/SVG/XML/manifest/plain. HTML входит в стандартный набор gzip nginx. Кеширование index и immutable assets сохранено; API остаётся на отдельном origin. Новые npm-зависимости не добавлялись. [Описание директив nginx](https://nginx.org/en/docs/http/ngx_http_gzip_module.html).

Read-only проверка работающего test подтвердила, что gzip уже был включён: HTML и текущий JavaScript возвращают `Content-Encoding: gzip` и `Vary: Accept-Encoding`. Эта задача закрепляет конфигурацию в репозитории; серверный nginx и production не перезапускались. Локальный Vite используется как сервер разработки; сжатие релизной статики проверено отдельным временным nginx на 127.0.0.1:5188, затем он остановлен.

Реальная HTTP-проверка собранного приложения в nginx: распакованные ответы побайтно совпадают с несжатыми; `Vary` и immutable-кеш сохранены. Ориентировочное уменьшение: HTML 48%, входной JavaScript 65%, основной CSS 73%. Точные размеры относятся к проверенному артефакту и записаны в `temp/world-requests-artifacts/gzip-verified.json` вне Git.
