# Таблица истории игр

Цель: таблица с номером, ставкой, участниками через UserAvatar и датой/временем в две строки.
Контекст: продолжение feature/09-game-history; локальный frontend обращается к тестовому API.

## Группа A: Интерфейс
- [x] A1. Общая таблица для всех четырёх игр с кубком победителя и полным публичным профилем участника.
- [x] A2. Кнопки сегодня/вчера/неделя/месяц/все вместо поиска, отдельный запрос сгруппированных ставок.
- [x] A3. Сохранять фильтры в URL; сбрасывать ставку и страницу при смене периода, игнорировать устаревшие ответы.

## Группа B: Проверка
- [x] B1. Пройти unit/SSR проверки и production build.
- [ ] B2. Влить в test, проверить выкладку и локальный frontend.

Критерии: одинаковая история четырёх игр, точная пагинация, реальные рейтинги, отдельные запросы ставок по периоду.

Проверки: 92 existing/unit/SSR теста и 4 новых теста useGameHistory прошли; сборка успешна. SSR проверяет настоящие UserAvatar и SVG кубка, табличные заголовки, дату/время и рейтинг из вложенного профиля. Проверены отдельные запросы группировки, смена периода/ставки, возврат по истории URL, recent-префикс, ошибки и устаревшие ответы. Визуальная браузерная проверка недоступна в текущей сессии.
