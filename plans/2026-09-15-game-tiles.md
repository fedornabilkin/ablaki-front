# Переход по игровой плитке

Цель: открывать тип игры кликом по всей плитке, убрать отдельную кнопку.
Контекст: страница /games, существующие маршруты четырёх игр.

## Группа A: Интерфейс
- [x] A1. Обернуть каждую плитку в router-link, убрать кнопку и сохранить переход с клавиатуры и открытие в новой вкладке.
- [ ] A2. Проверить сборку и существующие тесты, выложить на test.

Критерий: вся площадь плитки является ссылкой; кнопок «Открыть игру» нет.
