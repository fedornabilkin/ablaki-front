# Компактный поиск и сброс

## Цель и контекст

Убрать подпись над поиском, расположить компактный сброс крестиком рядом с полями. Сохранить незавершенные изменения черно-оранжевой темы в рабочем дереве.

## Группа A: Интерфейс

- [x] A1. В общем ListFilters оставить «Поиск» в placeholder и доступное имя поля.
- [x] A2. Заменить текстовый сброс на кнопку с Font Awesome крестиком, tooltip и aria-label; исключить отдельную строку кнопки.
- [x] A3. Добавить такой же сброс поиска и категории рецептов.
- [x] A4. Отображать сообщения об ошибках входа из нового ответа HTTP 401.

## Группа B: Проверки

- [x] B1. Выполнить npm run test:unit — 72 проверки прошли.
- [x] B2. Итоговая npm run build и diff --check прошли; остается предупреждение Vite о размере ui chunk больше 500 kB.

## Критерии готовности

Сброс остается на строке с поиском или последним рядом фильтров при переносе полей. Поиск и фильтры сохраняют прежнее управление URL. Владелец разрешил commit/push master с русским сообщением; push запускает штатный CI и деплой. Незавершенные изменения темы в других файлах не входят в коммит.
